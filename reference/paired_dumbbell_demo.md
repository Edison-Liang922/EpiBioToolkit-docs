# Demo data for paired dumbbell + heatmap plot

Example input for `plot_paired_dumbbell_heat`.

## Usage

``` r
paired_dumbbell_demo
```

## Format

A list with:

- data:

  Data frame containing sample-level values.

- sample_col:

  Sample column name.

- order_col:

  Ordering column name.

- heat_cols:

  Categorical columns for heatmap.

- value1_col:

  First continuous value column.

- value2_col:

  Second continuous value column.
