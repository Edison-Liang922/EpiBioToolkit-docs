# Demo data for advanced volcano plot

Example input for `plot_volcano_advanced`.

## Usage

``` r
volcano_advanced_demo
```

## Format

A data.frame with:

- logFC:

  log2 fold-change.

- P_value:

  p-value.

- logCPM:

  log expression for point size.

- gene:

  Gene symbol/ID.
