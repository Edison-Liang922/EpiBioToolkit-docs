# Demo data for circular hierarchical graph

Example input for `plot_ccgraph`, `gather_graph_node`, and
`gather_graph_edge`.

## Usage

``` r
ccgraph_demo
```

## Format

A list with:

- df:

  Data frame containing hierarchy and value columns.

- index:

  Hierarchy columns used for plotting.

- value:

  Value column used for node size.

- root:

  Root node name.

- gene_special:

  Optional gene annotations (Gene, Type).
