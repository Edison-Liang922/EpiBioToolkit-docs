# Demo Outcome Data for Colocalization

A small demo GWAS outcome dataset for \`Bio_coloc\`.

## Usage

``` r
outcome_coloc_demo
```

## Format

A data frame with columns:

- snp:

  Variant ID.

- pval:

  P-value.

- beta:

  Effect size.

- varbeta:

  Variance of beta (SE^2).

- pos:

  Base-pair position.

- maf:

  Minor allele frequency.
