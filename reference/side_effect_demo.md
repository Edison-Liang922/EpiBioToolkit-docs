# Demo data for side-effect stacked plot

Example data for `plot_side_effect_stack`.

## Usage

``` r
side_effect_demo
```

## Format

A list with:

- res_phe_all:

  Data frame containing required columns: `outcome`, `id.exposure`,
  `trait`, `tissue`, `p_side_effect`, `or_side_effect`.

- map_df:

  Mapping table with columns `id` and `group`.
