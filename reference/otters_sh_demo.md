# Demo config for OTTERS script generation

A small list of example file paths and parameters for
`Bio_OTTERS_create_sh` (stage 1 and stage 2).

## Usage

``` r
otters_sh_demo
```

## Format

A list with the following fields:

- stage1:

  A list of parameters for OTTERS stage 1 (training).

- stage2:

  A list of parameters for OTTERS stage 2 (testing).

## Source

Simulated example for documentation and testing.
