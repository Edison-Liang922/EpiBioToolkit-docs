# Demo data for diagnostic ROC

Example input for `plot_diagnostic_roc`.

## Usage

``` r
diagnostic_roc_demo
```

## Format

A list with:

- expr:

  Expression matrix (genes x samples).

- group_df:

  Data frame with columns `sample` and `group`.

- target_genes:

  Character vector of genes for ROC.
