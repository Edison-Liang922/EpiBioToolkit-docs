# Write harmonised data to file

Save harmonised data for an exposure-outcome pair to an Excel file.

## Usage

``` r
Bio_MR_write_harmonized(harmonized_dat, out_file, overwrite = TRUE)
```

## Arguments

- harmonized_dat:

  data.frame. Harmonised data.

- out_file:

  Character. Output file path (xlsx).

- overwrite:

  Logical. Whether to overwrite existing file.

## Value

The output file path.
