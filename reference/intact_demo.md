# Demo Data for INTACT

A small demo dataset containing coloc and TWAS inputs for
\`Bio_INTACT\`.

## Usage

``` r
intact_demo
```

## Format

A list with two elements:

- coloc:

  Colocalization summary data matching \`Bio_coloc\` output columns
  (gene, nsnp, PP.H0.abf to PP.H4.abf).

- twas:

  TWAS summary data with z-scores and P-values.
