# Gene Annotation (hg38)

Gene annotation table for mapping Ensembl gene IDs to HGNC symbols.

## Usage

``` r
gene_anno_hg38
```

## Format

A data frame with the following columns:

- Gene stable ID:

  Ensembl gene ID.

- HGNC symbol:

  HGNC gene symbol.
