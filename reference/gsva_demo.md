Example input for `plot_gsva_limma_barplot`.

## Usage

``` r
gsva_demo
```

## Format

A list with:

- expr:

  Expression matrix (genes x samples).

- gene_sets:

  List of gene sets.

- group:

  Group factor with sample names.
