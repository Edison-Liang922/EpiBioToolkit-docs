# Demo Data for Stepwise Regression

A small demo dataset for \`Epi_Stepwise_Regression\`.

## Usage

``` r
stepwise_demo
```

## Format

A data frame with columns:

- cancer:

  Binary outcome (0/1).

- sex:

  Sex (Male/Female).

- age:

  Age in years.

- BMI:

  Body mass index.

- smoking:

  Smoking status (Yes/No).

- hypertension:

  Hypertension status (Yes/No).

- diabetes:

  Diabetes status (Yes/No).

- surgery_time:

  Surgery time (minutes).
