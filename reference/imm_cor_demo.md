# Demo data for immune correlation plots

Example input for `plot_imm_cor_heatmap` and `plot_imm_sig_scatters`.

## Usage

``` r
imm_cor_demo
```

## Format

A list with:

- imm_wide_data:

  Matrix/data.frame of immune proportions (samples x cell types).

- expr_matrix:

  Expression matrix (genes x samples).

- genes:

  Character vector of genes for heatmap.

- gene:

  Single gene for scatterplots.
