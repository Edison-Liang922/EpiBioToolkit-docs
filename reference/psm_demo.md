# Demo Data for PSM

A small demo dataset for \`Epi_PSM_match\`.

## Usage

``` r
psm_demo
```

## Format

A data frame with columns:

- treat:

  Binary treatment/exposure (0/1).

- sex:

  Sex (Male/Female).

- age:

  Age in years.

- BMI:

  Body mass index.

- smoking:

  Smoking status (Yes/No).

- hypertension:

  Hypertension status (Yes/No).

- diabetes:

  Diabetes status (Yes/No).
