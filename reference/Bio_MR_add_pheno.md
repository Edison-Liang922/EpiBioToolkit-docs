# Add phenotype column

Utility function for MR workflows. It adds or overwrites a phenotype
column.

## Usage

``` r
Bio_MR_add_pheno(data, pheno_name, pheno_col = "phenotype")
```

## Arguments

- data:

  A data.frame.

- pheno_name:

  Character. Phenotype name to assign.

- pheno_col:

  Character. Column name for phenotype.

## Value

A data.frame with a phenotype column.
