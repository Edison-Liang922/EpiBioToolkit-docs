# Demo data for batch boxplot

Example input for `plot_batch_boxplot`.

## Usage

``` r
batch_boxplot_demo
```

## Format

A list with:

- expr:

  Expression matrix (genes x samples).

- group_df:

  Data frame with columns `sample` and `group`.

- group_order:

  Suggested group order.
