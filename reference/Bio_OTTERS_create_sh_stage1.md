# Create OTTERS stage 1 training scripts

Generate bash scripts for OTTERS stage 1 (training) and a \`run_me.sh\`
launcher script.

## Usage

``` r
Bio_OTTERS_create_sh_stage1(
  gwas_file,
  anno_file,
  out_dir,
  nthread,
  model = "PT,lassosum,PRScs,SDPR",
  env_file = "~/.otters_env",
  parallel = TRUE,
  print = FALSE,
  cl = NULL
)
```

## Arguments

- gwas_file:

  Character vector. Summary statistics files used for training
  (typically eQTL summary stats).

- anno_file:

  Character vector or scalar. OTTERS annotation file path(s) (e.g.,
  \*\_hg38_anno.txt generated by `Bio_OTTERS_format_eqtl`).

- out_dir:

  Character vector or scalar. Base output directory for stage 1.

- nthread:

  Integer. Number of threads for OTTERS.

- model:

  Character. Comma-separated models string for OTTERS training.

- env_file:

  Character. Path to OTTERS environment config file. The file should
  have at least 4 rows: OTTERS_DIR, SDPR_DIR, Exp_geno_chr, PATH (one
  per row).

- parallel:

  Logical. If TRUE, \`run_me.sh\` joins commands with \`&\`.

- print:

  保留参数，暂不使用。

- cl:

  保留参数，暂不使用。

## Value

A list with:

- \`code_files\`: vector of generated \`stage1.sh\` paths.

- \`run_files\`: vector of generated \`run_me.sh\` paths.

## Details

Stage 1 is used to train weights (typically eQTL weights). The input
\`gwas_file\` here refers to the summary statistics used for training;
in practice this is usually eQTL summary stats. The function writes one
\`stage1.sh\` under each output folder and a \`run_me.sh\` that can be
executed to run all generated scripts.

Output structure (per input summary file):

- \`out_dir/basename(gwas_file)\_stage1/code_temp/stage1.sh\`

- \`out_dir/run_me.sh\`

The \`env_file\` is a plain text file with at least 4 rows (one per
line):


    /path/to/OTTERS
    /path/to/SDPR
    /path/to/geno/chr_prefix
    /path/to/conda/bin

These are exported into the script as OTTERS_DIR, SDPR_DIR,
Exp_geno_chr, and PATH (prefix), respectively.
