# Demo data for LDSC/MTAG workflows

Example inputs for `Bio_LDSC_R`, `Bio_LDSC_conda`, and `Bio_MTAG`.

## Usage

``` r
ldsc_mtag_demo
```

## Format

A list with the following fields:

- ldsc_r_demo:

  A list containing `sumstats_list`, `traits`, and `col_map` for
  `Bio_LDSC_R`.

- ldsc_conda_demo:

  A list of example parameters for `Bio_LDSC_conda`.

- mtag_demo:

  A list of example parameters for `Bio_MTAG`.

## Source

Simulated example for documentation and testing.
