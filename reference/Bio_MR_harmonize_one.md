# Harmonise one exposure with one outcome

Perform allele harmonisation for a single exposure-outcome pair.

## Usage

``` r
Bio_MR_harmonize_one(exposure_dat, outcome_dat)
```

## Arguments

- exposure_dat:

  data.frame. TwoSampleMR exposure data.

- outcome_dat:

  data.frame. TwoSampleMR outcome data.

## Value

A harmonised data.frame. Returns NULL if input is empty.
