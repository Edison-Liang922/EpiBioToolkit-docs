# Demo data for immune boxplot

Example input for `plot_imm_boxplot`.

## Usage

``` r
imm_boxplot_demo
```

## Format

A data.frame with:

- Sample:

  Sample ID.

- Group:

  Group label.

- CellType:

  Immune cell type.

- Composition:

  Cell proportion (0-1).
