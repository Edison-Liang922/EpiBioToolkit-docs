# Demo Data for Elastic Net

A small demo dataset for \`Epi_ElasticNet\`.

## Usage

``` r
elasticnet_demo
```

## Format

A data frame with columns:

- cancer:

  Binary outcome (0/1).

- sex:

  Sex (Male/Female).

- age:

  Age in years.

- BMI:

  Body mass index.

- smoking:

  Smoking status (Yes/No).

- hypertension:

  Hypertension status (Yes/No).

- diabetes:

  Diabetes status (Yes/No).

- stroke:

  Stroke history (Yes/No).

- dyslipidemia:

  Dyslipidemia status (Yes/No).

- surgery_time:

  Surgery time (minutes).
